# Guides

Reference guides to keep open while you work through the challenges. Use them for looking things up, not for memorizing. After a few months of use, you won't need most of them.

| Guide | Answers the question | Most useful for |
| --- | --- | --- |
| [Problem types, baselines and metrics](problem-types-baselines-metrics.md) | What kind of problem is this? What do I try first? How do I measure it? | Every challenge; especially 01 |
| [Data preparation](data-preparation.md) | How do I clean and prepare this data, and what does each model need? | 02–08, 40 |
| [Splits, validation and leakage](splits-validation-leakage.md) | How do I split the data so the score tells the truth? Is this result real? | Every challenge with a model |
| [Choosing an algorithm](choosing-algorithms.md) | Which algorithm should I pick, and which settings matter? | 02–08 |
| [Writing specs for AI coding tools](specs-for-ai-coding.md) | How do I turn my decisions into prompts that produce correct ML code, and check the result? | Every challenge |
| [Deep learning field guide](deep-learning-field-guide.md) | Which architecture? What settings to start with? Why isn't training working? | 09–18, 22–25 |
| [Transformers and LLM concepts](transformers-and-llms.md) | Tokens, context, model sizes, memory, decoding, quantization, embeddings | 15–37 |
| [GenAI system design](genai-system-design.md) | Prompt, RAG, fine-tune or agent? How do I design and evaluate each? | 26–37, 41 |
| [Prompting patterns](prompting-patterns.md) | How do I write prompts for LLM features (classification, extraction, RAG, judges, agents)? | 26–37 |
| [Toolbox cheat sheet](toolbox-cheatsheet.md) | What's the command for…? (uv, git, Kaggle, Hugging Face, Ollama, MLX, Docker) | Always |
| [Portfolio and interviews](portfolio-and-interviews.md) | How do I present this work and answer interview questions? | After each phase; 41 |
